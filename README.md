## 📌 About the Project
SmartCart is a responsive e-commerce website developed using HTML, CSS, and JavaScript. It provides users with a simple and convenient online shopping experience.

Users can explore products, add items to their shopping cart, remove products, and calculate the total price.

## ✨ Features
- Attractive homepage
- Responsive user interface
- Product listing
- Add to Cart functionality
- Remove products from cart
- Automatic total price calculation
- Shopping cart management
- Checkout notification
- Navigation menu

## 💻 Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality

## 🚀 How to Run
1. Open the live website link.
2. Explore the available products.
3. Click Add to Cart to select products.
4. View your shopping cart.
5. Remove products if required.
6. Check the total price.
